# Aegis — AI 금융 리서치 대시보드

Yahoo Finance의 모든 종목(주식·ETF·지수·암호화폐·환율·선물)을 검색해 담고, 가격·뉴스·재무 데이터를 한 화면에서 분석하는 Streamlit 앱입니다. Google Gemini가 뉴스를 읽고 브리핑과 시나리오 전망을 만들어 줍니다.

## 화면 구성

| 페이지 | 내용 |
|---|---|
| **대시보드** | 요약 카드, 관심 종목 표(등락률·90일 추이), 상대 성과 차트, 등락 히트맵. 표의 행을 누르면 종목 분석으로 이동 |
| **종목 분석** | 캔들/라인 차트, 기간 전환(1개월~전체), 이동평균·볼린저·거래량·RSI·MACD, 기간 수익률, 밸류에이션 지표, AI 브리핑, 종목 뉴스, 기업 개요 |
| **뉴스** | 관심 종목 뉴스 통합 피드(중복 제거), 종목·키워드 필터, 뉴스 분위기 점수, 많이 보도한 매체 |
| **AI 전망** | Gemini가 뉴스를 해석해 강세·기준·약세 확률과 가정을 산출 → 몬테카를로 시뮬레이션(두꺼운 꼬리 + 돌발 이벤트). 가정은 슬라이더로 직접 조정 가능 |
| **포트폴리오** | 비중 편집, 동일 비중·최소 변동성·최대 샤프·위험 균형 자동 배분, 위험·수익 지표, 벤치마크 비교, 효율적 투자선, 위험 기여도, 상관관계 |
| **백테스트** | 이동평균 교차·RSI 역추세·볼린저 반등 전략, 매매 시점 표시, 월별 수익률, 이동평균 조합 탐색 |
| **가치평가** | DCF, 주당 내재가치와 현재가 비교, 시장이 반영한 성장률(역DCF), 민감도 히트맵 |
| **AI 애널리스트** | 관심 종목 데이터와 전망 결과를 읽고 답하는 대화형 분석 |

세부 디테일
- 상승·하락 색을 **한국식(빨강↑ 파랑↓)** 과 미국식 중에서 고를 수 있습니다.
- 원화는 조·억 단위, 달러는 T·B·M 단위로 표시합니다.
- Gemini의 사고 과정을 실시간으로 보여주고, 토큰 사용량을 표시합니다.
- 모델이 사고 수준 설정을 지원하지 않으면 자동으로 다시 시도합니다.

## 저장소에 올릴 파일

```
main.py
requirements.txt
.env
.gitignore
README.md
LICENSE
.streamlit/config.toml   ← 다크 테마와 Pretendard 글꼴
```

`.env`와 `.streamlit` 폴더는 점으로 시작해서 탐색기에서 숨겨질 수 있습니다. GitHub 웹에서 **Add file → Create new file**을 누르고 파일 이름에 `.env` 또는 `.streamlit/config.toml`을 입력한 다음 내용을 붙여넣으면 됩니다. 폴더도 같이 만들어집니다.

## API 키 설정 (.env)

```env
GEMINI_API_KEY=AIza로_시작하는_키
GEMINI_MODEL=gemini-flash-latest
GEMINI_THINKING_LEVEL=high
```

- 키는 [Google AI Studio](https://aistudio.google.com/apikey)의 **Create API key**에서 받습니다. 보통 `AIza`로 시작하는 39자입니다.
- `.env` 값이 Streamlit Secrets보다 우선합니다. 예전에 Secrets에 넣은 키가 있다면 지워 두는 게 깔끔합니다.
- 사이드바의 **Gemini → 연결 테스트**로 키와 모델 이름을 바로 확인할 수 있습니다.

> **공개 저장소 주의:** 공개 저장소에 키를 올리면 Google이 키를 '유출됨'으로 자동 차단할 수 있습니다(`API key was reported as leaked`). 저장소를 **비공개(private)** 로 두는 걸 권장합니다. 차단되면 새 키를 발급해 `.env`만 바꾸면 됩니다.

## 배포 (Streamlit Community Cloud)
1. 위 파일들을 GitHub 저장소 루트에 올립니다.
2. Streamlit Community Cloud에서 저장소를 연결하고 Main file path를 `main.py`로 지정합니다.
3. 이미 배포된 앱이라면 **Reboot app**을 눌러 새 의존성을 설치합니다.

## 로컬 실행
```bash
pip install -r requirements.txt
streamlit run main.py
```

## 한계
교육·연구용 도구입니다.
- 데이터 출처의 한계
  - Yahoo Finance 데이터와 검색은 공식 API가 아니어서 지연·누락·요청 제한이 있을 수 있습니다.
  - Google News RSS도 형식이 바뀔 수 있습니다.
  - 한글 회사명은 Yahoo 검색에서 잘 안 잡힐 수 있으니 영문명이나 6자리 코드로 검색하세요.
- 모형과 AI의 한계
  - AI 해석과 시뮬레이션은 틀릴 수 있습니다.
  - 효율적 투자선과 최적 비중은 과거 평균에 민감합니다.
  - 백테스트는 세금·슬리피지를 반영하지 않습니다.
- 통화가 다른 자산을 섞은 포트폴리오는 환율 효과를 반영하지 않습니다.
